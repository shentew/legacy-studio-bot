# Legacy Studio Bot

Bot de Discord con sistema de tickets, sugerencias, auto-moderación y dashboard web.

## Características
- Sistema de tickets con transcripciones
- Panel de sugerencias con aprobación/rechazo
- Auto-moderación de palabras prohibidas
- Dashboard web para configuración
- Comandos de utilidad (serverinfo, userinfo, avatar, encuesta, sorteo)

## Instalación
1. Clona este repositorio
2. Instala dependencias: `npm install`
3. Crea un archivo `.env` con tu TOKEN de Discord
4. Ejecuta: `npm start`
